# Force Divided - React Learning Documentation

This documentation is designed to help you prepare for React job interviews by explaining the core concepts used in this application. The app is a Star Wars sequel trilogy opinion platform built with modern React patterns.

## Documentation Structure

- **[BASICS.md](./BASICS.md)** - Core React concepts and fundamentals

  - React DOM setup and lifecycle
  - StrictMode

- **[ADVANCED.md](./ADVANCED.md)** - Advanced topics and setup

  - State management patterns
  - Hooks (useState, useEffect)

## Application Overview

This is a React 19 application that displays Star Wars sequel trilogy movies in a card grid layout. The app demonstrates:

- **Component-based architecture** - Breaking UI into reusable pieces
- **Modern React patterns** - Using functional components and hooks
- **TypeScript** - Type safety throughout the codebase
- **Tailwind CSS** - Utility-first styling
- **Vite** - Fast development and build tooling

## Key Files to Study

- `src/main.tsx` - Application entry point, DOM setup
- `src/App.tsx` - Root component, demonstrates mapping and JSX
- `src/components/MovieCard.tsx` - Reusable component with props
- `src/components/Header.tsx` - Component with state and effects
